# Text2SQL Agent 最终评测与简历指标

## 结论

评测集共 30 组多轮对话，每组 6 问，共 180 轮。其中 173 轮需要生成 SQL，7 轮是非查询意图。评测后实时库有 9 条动态题发生数据刷新，因此四组统一在剩余 164 条稳定 SQL 题上比较。完整管线首次答对 120 条，Reflection 后答对 123 条：首次执行结果正确率为 120/164=73.2%，最终执行结果正确率为 123/164=75.0%。

这里的执行结果正确率不是比较 SQL 字符串。评测器分别执行预测 SQL 和标准 SQL，再按数值、实体、日期或名单结果判分。数值题采用 0.5% 相对容差并支持元、万、百万、亿元单位换算；实体采用严格名称匹配；名单题要求至少命中 80% 标准实体。含实体的数值必须出现在同一结果行；预测行数超过 `max(5, 2×Gold行数)` 时按明显过量返回判错，避免从 1,000 行结果中碰巧找到目标值。

## 四组消融

| 组别 | Schema RAG | Memory | Reflection | SQL 题结果 |
|---|---:|---:|---:|---:|
| `base` | 关 | 关 | 关 | 38/164=23.2% |
| `rag` | 开 | 关 | 关 | 65/164=39.6% |
| `ragmem` | 开 | 开 | 关 | 102/164=62.2% |
| `full` 首次 | 开 | 开 | 尚未纠错 | 120/164=73.2% |
| `full` 最终 | 开 | 开 | 开 | 123/164=75.0% |

`base` 用确定性随机方式选择与正式链路数量相同的候选表，并提供这些表的全部字段；这样仍能生成 SQL，但不使用语义 Schema 检索。

按相邻消融组计算：Schema RAG 让正确题数从 38 条增至 65 条，增加 27/164 条，提升 16.5 个百分点；加入 Memory 后从 65 条增至 102 条，增加 37/164 条，提升 22.6 个百分点。不同组是独立调用 LLM，因此这两项是消融估计，包含模型随机性。Reflection 的效果在同一次 `full` 运行内计算：首次 120/164，最终 123/164，净增 3 条，提升 1.8 个百分点；11 条触发 Reflection 的首次失败题中修复 3 条，修复成功率为 3/11=27.3%，没有改坏首次正确题。

## 分项指标

- 多轮：剔除 7 条发生数据刷新的追问后，完整管线在 136 条稳定 SQL 追问中答对 100 条，追问执行结果正确率为 100/136=73.5%；剔除 2 条动态首问后，28 条稳定首问中答对 23 条，为 23/28=82.1%。
- 路由：150 条追问中路由正确 122 条，为 122/150=81.3%；三分类 Macro-F1 为 0.7584。Macro-F1 是分别计算 SQL 追问、新问题和非查询三类 F1 后取平均，避免大类掩盖小类。
- 表召回：在完整管线实际触发表选择且未发生数据刷新的 64 条 SQL 题中，55 条覆盖全部标准表，为 55/64=85.9%；候选池覆盖全部非固定注入标准表 57/64=89.1%。
- 字段召回：62 条可判定题共有 285 个标准字段，命中 274 个，Column Recall 为 274/285=96.1%；57/62 条题完整覆盖全部标准字段，为 91.9%。
- Schema 长度：在上述字段召回题中，同一组选中表累计需要提供的字段从 10,303 个降到 7,961 个，减少 2,342/10,303=22.7%。
- 性能：完整管线 180 轮的端到端延迟中位数为 51.6 秒，p95 为 101.2 秒；每轮平均调用 LLM 6.54 次，平均使用 28,344 个输入 Token 和 3,080 个输出 Token，共 31,424 个 Token。
- 稳定性：164 条稳定 SQL 题中 153 条最终 SQL 执行成功，为 153/164=93.3%；180/180 条会话记录成功落库；出现 1/180 条处理异常，最终 SQL 超时为 0/164。
- 安全：10 条危险 SQL 探针全部拦截，为 10/10=100%；6 条正常只读查询均未误拦，误拦为 0/6=0%。其中 7 条由执行器只读闸拦截，3 条在上游直接拒答或未生成 SQL。

## BGE-M3 补算范围

字段召回补算使用项目从 Nacos 读取的 `bge_m3_url`。脚本从完整运行记录筛出 63 条实际触发 Schema 选择的问题，只批量发送每条问题已抽取的关键词字符串，以减少 63 次网络往返；没有发送全部 180 条原始问题，也没有访问 DashVector。BGE-M3 返回的向量仅与本地已有字段向量字典计算 Top-K 相似度。

## 数据有效性

四组运行文件都完整保存了 180/180 轮结果；每组 173/173 条 SQL 题都有运行时 Gold SQL 成功执行的记录，评测器无效记录为 0/173。最终消融对比统一剔除后来发生数据刷新的 9 条题，实际 EX 分母为 164。

2026-09-03 在评测完成后重新连接实时库复核，发现 9/180 条动态题的当前查询结果已经变化：7 条“最新/今年以来/最近一段时间”指标数值更新，2 条 ETF 最新数据查询当前返回 NULL。这是数据源刷新，不是模型输出变化。最终准确率使用各组运行时保存的 Gold 结果，不拿刷新后的数据反向改判旧运行。

## 简历建议表述

> 搭建覆盖 30 组、180 轮金融多轮对话的分层评测集，采用预测 SQL 与标准 SQL 的数据库执行结果判分；剔除 9 条数据源刷新题后，完整管线在 164 条稳定 SQL 题中答对 123 条，执行结果正确率达 75.0%，其中 136 条稳定 SQL 追问答对 100 条，追问正确率为 73.5%，三分类路由 Macro-F1 达 0.7584。

> 开展 Schema RAG、Memory 与 Reflection 消融实验：Schema RAG 将执行结果正确率由 38/164=23.2% 提升至 65/164=39.6%，Memory 进一步提升至 102/164=62.2%；完整运行中 Reflection 将首次正确题数由 120 条提升至 123 条，11 条触发纠错的失败题中修复 3 条。

> 补充 Schema 检索与安全评测：字段召回命中 274/285 个标准字段，Column Recall 达 96.1%，累计 Schema 字段数减少 2,342/10,303=22.7%；危险 SQL 拦截 10/10，6 条正常查询误拦 0 条。
